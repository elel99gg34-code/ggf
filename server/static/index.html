발급 기록이 임시 저장소에 있어요. 서버가 다시 시작되면 기록이 사라져요(발급한 키는 계속 쓸 수 있어요). Render에서 DATABASE_URL을 연결해 주세요.

종류

CSV 내려받기

취소는 기록에만 남아요. 앱은 인터넷 없이 키를 확인하기 때문에, 이미 등록한 키를 원격으로 막을 수는 없어요.

    와디즈 서포터 명단을 붙여 넣거나 CSV 파일을 고르세요. 열 순서: 이름, 이메일, 주문번호 (첫 줄에 머리글이 있어도 돼요)

    무료 Gmail은 하루 100통까지 보낼 수 있어요. 넘으면 다음 날 자동으로 이어서 보내요.

    발송 상태

    메일 설정

    설치 파일은 구글 드라이브 등에 올리고 '링크가 있는 모든 사용자' 공유 링크를 넣으세요. 고객에게는 이 링크 대신 서버 주소가 가서, 나중에 파일을 바꿔도 메일을 다시 보낼 필요가 없어요. 키가 없으면 설치해도 쓸 수 없어요.

    Gmail 연결 (처음 한 번)
    1. 판매용 Gmail 계정으로 로그인한 상태에서 script.google.com 새 프로젝트를 여세요. 개인 계정으로 하면 고객에게 그 주소가 보여요.
    2. 아래 코드를 복사해서 원래 있던 내용을 지우고 붙여 넣은 뒤 저장하세요.
    3. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 → 실행 사용자 나, 액세스 권한 모든 사용자 → 배포 → 권한 허용(‘고급 → 안전하지 않음으로 이동’이 나오면 눌러도 돼요. 내가 만든 코드예요).
    4. 나온 웹 앱 URL을 아래에 붙여 넣고 연결 확인을 누르세요.
