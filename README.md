# YTOrganizer

유튜브 구독 채널과 재생목록을 한 번에 정리하는 윈도우 데스크톱 앱.

- **구독 정리** — 오래 안 올라오는 채널, 폐쇄된 채널, 이름 바뀐 채널을 찾아 일괄 정리
- **자동 분류** — 좋아요 누른 영상을 주제별 재생목록으로 분산 (규칙 기반, AI는 선택)
- **재생목록 청소** — 삭제·비공개된 영상과 중복 항목 제거, 정렬, 병합
- **되돌리기** — 실행한 작업을 역순으로 복원

## 이 앱이 왜 이렇게 생겼나

유튜브 API는 프로젝트당 **하루 10,000유닛**으로 고정돼 있고, 돈을 내고 늘릴 수 없다.
읽기는 1유닛인데 **쓰기는 전부 50유닛**이라 하루에 가능한 쓰기 작업은 200번이 상한이다.

그래서 이 앱은:

1. **한 번 동기화해 로컬 SQLite에 담고**, 탐색·필터·미리보기는 전부 0유닛으로 한다.
2. **쓰기는 미리보기 → 승인 → 실행** 순서를 거친다. 바뀔 내용과 드는 유닛을 먼저 보여준다.
3. **할당량이 떨어지면 실패가 아니라 일시정지**한다. 다음 날 남은 것부터 이어서 한다.
4. 실행한 작업은 **되돌릴 수 있다**(되돌리기도 유닛을 쓰므로 비용을 함께 표시한다).

## API로 할 수 없는 것

공식 API가 막아둔 영역이라 이 앱도 못 한다. 미리 알아두는 게 좋다.

- 나중에 볼 동영상(WL) 접근
- 시청 기록 조회·삭제
- 추천 "관심 없음" 피드백

"알고리즘 관리"는 **구독 정리 + 재생목록 큐레이션**이라는 간접 수단으로 접근한다.

## 개발

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest          # 실제 API 없이 전부 검증
.venv/bin/python -m ytorg.cli demo  # 가짜 계정으로 전체 흐름 시연
```

## 설치 파일 만들기

`packaging/build.bat` 을 윈도우에서 실행한다. 자세한 건 `docs/` 참고.
