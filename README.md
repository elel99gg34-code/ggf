# 로블록스 잠수 방지 (Roblox AFK Keeper)

로블록스는 **20분 동안 입력이 없으면 자동으로 강퇴**한다.
이 프로그램은 로블록스 창을 찾아서 몇 분 간격으로 무해한 입력(카메라 회전 ·
줌 · 마우스 미세 이동 등)을 자동으로 보내 잠수로 인식되지 않게 한다.

- 설치 파일(Setup.exe) / 무설치 exe 둘 다 만들 수 있다
- 파이썬 표준 라이브러리만 사용 — 추가 패키지 설치 불필요
- GUI로 간격과 입력 종류를 직접 고를 수 있다
- 내가 직접 게임을 조작 중이면 자동으로 입력을 건너뛴다

---

## 1. 설치 파일 만들기

Windows PC에서 **`build.bat` 을 더블클릭**하면 끝이다.

```
build.bat
```

빌드가 끝나면 `dist` 폴더가 열린다.

| 파일 | 설명 |
|---|---|
| `dist\RobloxAFK.exe` | 무설치 실행 파일. 이거 하나만 복사해서 아무데서나 실행하면 된다 |
| `dist\RobloxAFK-Setup-1.0.0.exe` | 설치 마법사. 시작메뉴 · 바탕화면 아이콘 · 자동 실행 등록까지 해준다 |

> **파이썬이 필요한 건 "만들 때"뿐이다.** 만들어진 exe는 파이썬 없는 PC에서도 돌아간다.
>
> - 파이썬이 없으면: https://www.python.org/downloads/ 에서 설치.
>   설치 화면 맨 아래 **`Add python.exe to PATH`** 체크 필수.
> - `Setup.exe`까지 만들려면 [Inno Setup 6](https://jrsoftware.org/isdl.php)이 필요하다.
>   없어도 `RobloxAFK.exe`는 정상적으로 만들어진다.

빌드 없이 바로 써보려면 `run_from_source.bat` 을 실행하면 된다.

---

## 2. 사용법

1. 로블록스로 게임에 접속한다
2. `RobloxAFK.exe` 실행
3. **입력 간격**을 정한다 (기본 3분 — 20분보다만 짧으면 된다)
4. **시작** 버튼

`지금 한 번 테스트` 버튼으로 입력이 실제로 먹히는지 먼저 확인해보는 걸 권장한다.

### 보낼 입력 고르기

| 입력 | 캐릭터 영향 | 설명 |
|---|---|---|
| 카메라 좌회전 / 우회전 (← →) | 없음 | **기본값.** 시점만 살짝 돌아간다 |
| 줌 인 / 줌 아웃 (I / O) | 없음 | 카메라 거리만 바뀐다 |
| 마우스 미세 이동 | 없음 | 3픽셀 움직였다가 바로 되돌린다 |
| 점프 (Space) | ⚠ 있음 | 캐릭터가 실제로 점프한다 |
| Shift 탭 | ⚠ 있음 | 게임에 따라 달리기/시프트락이 걸린다 |
| 좌클릭 | ⚠ 있음 | 도구 사용·UI 클릭이 될 수 있다 |

여러 개를 고르면 매번 무작위로 바꿔가며 보낸다.
**기본 설정(무해한 입력 4종 + 마우스)은 캐릭터를 전혀 움직이지 않는다.**

### 옵션

- **다른 창을 쓰고 있어도 로블록스를 잠깐 활성화해서 입력**
  켜두면 다른 작업 중에도 동작한다. 입력을 보내는 0.2초 동안만 로블록스 창이
  앞으로 나왔다가 원래 창으로 돌아온다.
  이게 거슬리면 끄면 되는데, 그 경우 로블록스가 활성 창일 때만 동작한다.
- **입력 후 원래 쓰던 창으로 되돌리기** — 위 옵션과 같이 쓴다.
- **내가 직접 조작 중이면 입력 건너뛰기**
  최근 45초 안에 내가 직접 키보드·마우스를 썼으면 그냥 넘어간다.
  (프로그램이 보낸 입력과 사람이 보낸 입력을 구분해서 판단한다.)
- **흔들림(초)** — 간격에 ±N초 무작위를 더해서 정확히 일정한 주기를 피한다.

설정은 `%APPDATA%\RobloxAFK\config.json` 에 자동 저장된다.

### 콘솔로 쓰기

```bat
RobloxAFK.exe --cli                    :: 콘솔 모드
RobloxAFK.exe --cli -i 5               :: 5분 간격
RobloxAFK.exe --cli -a jump -a zoom_in :: 보낼 입력 직접 지정
RobloxAFK.exe --cli --max-runtime 120  :: 2시간 뒤 자동 종료
RobloxAFK.exe --cli --dry-run          :: 실제 입력 없이 동작만 확인
RobloxAFK.exe --list-actions           :: 가능한 입력 목록
```

## 3. 어떻게 "연결"되나

로블록스는 외부 프로그램이 붙을 수 있는 **공식 API를 제공하지 않는다.**
그래서 연결은 게임이 아니라 **운영체제 레벨**에서 이루어진다.

```
1. EnumWindows        로블록스 클라이언트 창을 찾는다 (창 클래스: WINDOWSCLIENT)
                      ※ Roblox Studio 는 자동으로 제외
2. SetForegroundWindow  필요하면 그 창을 잠깐 활성화
   + AttachThreadInput  (포그라운드 락을 우회하기 위해 스레드 입력을 붙임)
3. SendInput          스캔코드 기반 키/마우스 입력을 주입
4. SetForegroundWindow  원래 쓰던 창으로 복귀
```

핵심은 **`SendInput` + `KEYEVENTF_SCANCODE`** 다.
로블록스는 Raw Input을 읽기 때문에 `PostMessage`/`SendMessage` 같은 메시지
주입 방식은 통하지 않는다. 실제 키보드가 보내는 것과 똑같은 스캔코드 이벤트를
넣어야 게임이 입력으로 받아들이고, 그래야 `Player.Idled` 타이머가 초기화된다.

게임 메모리를 건드리거나 프로세스에 코드를 주입하지 않는다. 어디까지나
**"키보드를 대신 눌러주는 것"** 이다.

## 4. 문제 해결

**입력이 안 먹힐 때**
로블록스가 관리자 권한으로 실행 중이면, 권한이 낮은 프로그램은 입력을 보낼 수
없다(UIPI). `RobloxAFK.exe`를 우클릭 → **관리자 권한으로 실행**.

**"로블록스 창을 못 찾았다"**
게임에 실제로 접속한 상태여야 한다. 웹 브라우저의 로블록스 페이지는 인식하지
않는다. 게임을 켜면 자동으로 다시 붙으니 프로그램을 끌 필요는 없다.

**"로블록스 창 포커스 실패"**
전체화면(Fullscreen) 모드에서 가끔 발생한다. 로블록스를 **창 모드**나
**테두리 없는 창** 모드로 바꾸면 안정적이다. 실패해도 다음 차례에 자동 재시도한다.

**빌드할 때 백신이 exe를 잡을 때**
PyInstaller로 만든 exe는 서명이 없어서 오탐이 잦다. `dist` 폴더를 백신 예외로
등록하면 된다.

---

## 5. 알아둘 것

- 자동 입력은 로블록스 이용약관에서 권장되지 않는다. 단순 잠수 방지 용도로
  문제가 되는 경우는 드물지만, 판단은 본인 몫이다.
- 아이템 파밍 같은 **자동 플레이 용도로는 쓰지 마라.** 그건 제재 대상이다.
- 기본 설정은 캐릭터를 움직이지 않는 입력만 보내도록 되어 있다.

## 구조

```
build.bat                설치 파일 빌드 (이거 하나만 실행하면 된다)
run_from_source.bat      빌드 없이 바로 실행
src/roblox_afk.py        프로그램 본체 (엔진 + GUI + CLI)
build/roblox_afk.spec    PyInstaller 설정
build/make_icon.py       아이콘 생성 (외부 라이브러리 없이 .ico 를 직접 씀)
build/version_info.txt   exe 버전 정보
installer/RobloxAFK.iss  Inno Setup 설치 마법사 스크립트
tests/test_core.py       핵심 로직 테스트 (python -m unittest discover -s tests)
```
