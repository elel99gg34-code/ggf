# ggf

야간경기 전광판 컨셉의 숫자야구. 의존성 없는 단일 HTML 파일 하나.

```
open index.html
```

빌드 없음, 번들러 없음, 라이브러리 없음. `index.html`만 브라우저로 열면 끝.

## 규칙

1부터 9까지 **서로 다른 숫자**로 이루어진 정답을 맞힌다.

| 판정 | 조건 |
| --- | --- |
| `S` 스트라이크 | 숫자가 맞고 **자리도** 맞음 |
| `B` 볼 | 숫자는 맞지만 **자리가** 다름 |
| `OUT` | 하나도 안 맞음 |

모든 자리를 스트라이크로 채우면 끝내기 홈런. 제한 이닝을 넘기면 경기 종료.

## 난이도

| 모드 | 자릿수 | 제한 |
| --- | --- | --- |
| 싱글A | 3 | 9이닝 |
| 더블A | 4 | 10이닝 |
| 메이저 | 5 | 12이닝 |

## 조작

| 키 | 동작 |
| --- | --- |
| `1`–`9` | 숫자 입력 |
| `Enter` | 던지기 |
| `Backspace` | 한 칸 지우기 |
| `Esc` | 전부 지우기 |
| `H` | 힌트 (경기당 1회) |

## 안에 들어간 것

- 도트매트릭스 전광판 헤더와 야간 조명 글로우
- S/B/O 램프가 순차 점등되는 판정 연출, 투구 애니메이션
- WebAudio로 합성한 타격음·삼진음·함성 (라이브러리 없음, 토글 가능)
- 끝내기 홈런 시 캔버스 폭죽
- `localStorage`에 난이도별 전적과 최소 이닝 기록 저장 (실패해도 게임은 그대로 동작)
- `prefers-reduced-motion` 존중, 키보드 전용 조작 가능
