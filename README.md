## GGF 파크 나이트게임

투수가 구종별 궤적으로 던지고, 타이밍에 맞춰 스윙하면 타구가 물리 계산으로 날아간다.
야수 9명이 낙구지점을 쫓고, 잡으면 아웃·놓치면 주자가 베이스를 돈다.

### 조작

| 키 | 동작 |
| --- | --- |
| `Space` | 스윙 (그라운드를 탭해도 됨) |
| `←` `→` | 당겨치기 / 밀어치기 |
| `↑` | 어퍼스윙 — 장타가 늘지만 타이밍 허용치가 20% 좁아진다 |
| `Enter` | 다음 투구로 넘기기 |

화면 우하단 **포수 시점 인셋**이 스트라이크존과 날아오는 공의 높이·코스를 보여준다.
탑다운 필드만으로는 공의 높이를 읽을 수 없어서, 타이밍 판단은 이 인셋으로 한다.
지난 투구는 번호가 붙은 점으로 남는다 — 빨강은 스트라이크, 초록은 볼, 노랑은 타격.

### 구종

| 구종 | 구속 | 특징 |
| --- | --- | --- |
| 포심 | 94 | 거의 직선 |
| 슬라이더 | 86 | 횡으로 휜다 |
| 커브 | 78 | 크게 솟았다 떨어진다 |
| 체인지업 | 83 | 느리게 가라앉는다 |

### 타구 판정

스윙 타이밍 오차와 공이 존에서 벗어난 거리를 합쳐 컨택 품질을 3단계로 나눈다.
품질에 따라 타구속도·발사각이 정해지고, 나머지는 물리와 수비가 결정한다.

- 타구는 공기저항을 받으며 날아가고, 펜스(중앙 400ft / 폴 328ft)를 높이 9ft 위로 넘기면 홈런
- 펜스를 맞으면 튕겨 나오고, 땅에 닿으면 바운드 후 구른다
- 야수는 반응 0.5초 뒤 실제 주로를 따라 움직인다 — 닿을 수 있으면 포구, 아니면 안타
- 진루 수는 야수가 공을 확보한 시각과 중계 송구 시간을 주자의 도달 시간과 비교해 정한다

이 모델의 결과는 실제 야구 분포에 맞췄다. 인플레이 타구 4000개 기준:

| 지표 | 이 게임 | 실제 MLB |
| --- | --- | --- |
| 인플레이 안타율 | 31.7% | ~33% |
| 안타 중 2루타 | 18.4% | ~20% |
| 안타 중 홈런 | 17.0% | ~13% |
| 컨택 중 파울 | 21.3% | ~25% |

### 난이도

| 모드 | 타이밍 허용치 | 상대 타자 |
| --- | --- | --- |
| 연습 | ±0.25초 · 투구 22% 느리게 | 약함 |
| 정규 | ±0.19초 | 보통 |
| 포스트시즌 | ±0.15초 · 투구 12% 빠르게 | 강함 |

### 그 밖에

- 볼넷·삼진·희생플라이·병살·봉살·워크오프·연장(12회까지) 처리
- 이닝별 스코어보드, 볼카운트 램프, 주자 다이아몬드, 중계 로그
- WebAudio로 합성한 미트·타격·헛스윙·함성 (라이브러리 없음, 토글 가능)
- `prefers-reduced-motion` 존중, 난이도/사운드 설정은 `localStorage`에 저장 (실패해도 그대로 동작)

## 숫자야구

1부터 9까지 서로 다른 숫자를 맞힌다. 자리까지 맞으면 `S`, 숫자만 맞으면 `B`, 하나도 없으면 `OUT`.
3/4/5자리(9/10/12이닝) 난이도와 경기당 1회 힌트, 도트매트릭스 전광판 연출.
