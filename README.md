# 🥚 계란을 훔치다 (Steal an Egg)

로블록스풍 브라우저 게임. 알을 품은 생물에게서 **알을 훔치고 → 부화시켜 → 러닝머신에 올려 돈을 버는** 방치형 수집 게임이다.
빌드 도구·의존성 없음. `index.html` 을 브라우저로 열면 바로 실행된다.

**바로 하고 싶으면** → `steal-an-egg.html` 하나만 받아서 더블클릭. (모든 CSS/JS 가 인라인된 단일 파일, 139KB)

**소스로 실행**
```
git clone <repo> && cd ggf
# index.html 을 더블클릭하거나
npx http-server -p 8080 .   # → http://localhost:8080

node build.js               # 소스 수정 후 단일 파일 다시 생성
```

## 게임 루프

```
알 훔치기  →  부화기에 투입  →  성장 → 부화(등급 공개)  →  러닝머신 배치  →  자동 수익
                                                                    ↓
                                           러닝머신 확장 · 시설 업그레이드 · 다음 구역 해금
```

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 이동 (모바일은 왼쪽 화면 드래그 = 조이스틱) |
| `E` **꾹 누르기** | 알 훔치기 / 알 투입 / 쓰다듬기 / 부화 / 펫 배치·회수 / 구역 해금 |
| `B` | 상점 |
| `I` | 내 펫 |
| `H` | 도움말 |
| `ESC` | 닫기 |

## 훔치기 규칙

**일반 몹** — 옆에서 `E` 를 꾹 누르면 게이지가 찬다.
머리 위에 <b>❗</b> 가 뜨면 곧 뒤돌아본다는 신호이므로 **즉시 손을 뗀다**.
눈이 빨개진 상태에서 계속 붙잡고 있으면 들켜서 기절한다. (게이지는 손을 떼도 천천히만 줄어든다)

**보스 — 규칙이 다르다 👑**

구역마다 보스가 하나씩 있고 알을 3개 품고 있다.

- 예고(❗)가 **훨씬 짧고**, 알을 하나 뺏길 때마다 **분노**해서 더 짧아진다
- **무궁화꽃이 피었습니다** 룰 — 쳐다보는 동안엔 `E` 를 떼는 것만으로 부족하고 **완전히 멈춰 있어야** 한다
- 걸리면 **돌진**해서 플레이어를 날려버리고 (넉백 + 긴 기절), 가방에 있던 알 1개를 떨어뜨린다
- 대신 **등급 하한이 보장**되고, 알 3개를 모두 털면 격파 — 쿨다운 후 부활한다

## 구역 & 권장속도

권장속도 = 그 구역 생물의 초당 수익 기준값.

| 구역 | 일반 몹 | 엘리트 | 권장속도 | 해금 비용 | 보스 (등급 하한) |
|---|---|---|---|---|---|
| 🐔 농장 | 닭 | 갈색 닭 (2.5) | **1** | 무료 | 꼬꼬대왕 — 에픽 |
| 🦆 오리 연못 | 오리 | 백조 (380) | **150** | 2.5K | 마더덕 — 에픽 |
| 🦂 사막 | 전갈 | 킹 전갈 (2.6K) | **1,000** | 25만 | 스콜피온 킹 — 시크릿 |
| 🐯 정글 | 호랑이 | 백호 (2.6만) | **10,000** | 300만 | 정글 군주 — 디바인 |
| 🐋 바다 | 고래 | 범고래 (130만) | **500,000** | 6000만 | 리바이어던 — 코스믹 |
| 🦖 공룡 계곡 | 공룡 | 티라노 (450만) | **1,800,000** | 8억 | 화산의 폭군 — 코스믹 |
| 💀 우주 | 해골장군 | 해골왕 (4500만) | **18,000,000** | 150억 | 해골 대장군 — 영원한 |

구역은 **순서대로만** 해금된다. 생물마다 습성이 다르다 — 오리는 빠르게 도망치고, 전갈은 모래에 숨고,
호랑이는 들키면 덮치고, 고래는 물보라를 뿜고, 공룡은 발소리로 화면을 흔들고, 해골은 순간이동한다.

## 등급 & 아우라

| 등급 | 수익 배수 | 기본 확률 | 아우라 |
|---|---|---|---|
| 일반 | ×1 | 55.6% | 없음 |
| 레어 알 | ×3 | 26.7% | 물결 (푸른 기포) |
| 에픽 | ×9 | 12.2% | 자수정 (보랏빛 궤도 스파크) |
| 시크릿 | ×30 | 3.8% | 그림자 (검붉은 파편) |
| 디바인 | ×100 | 1.2% | 후광 (황금 광선 + 헤일로) |
| 코스믹 | ×350 | 0.38% | 성운 (은하 소용돌이 + 별) |
| 영원한 | ×1600 | 0.067% | 무한 (무지개 링 + 빛기둥) |

확률은 생물의 `luck` 값이 등급 tier 만큼 지수로 곱해져 상위 구역일수록 고등급이 잘 나온다.

**아우라 변형** — 등급 위에 한 번 더 곱해지는 희귀 오버레이: 기본(87%) / ✨빛나는 ×2 (10.5%) / 🌈무지개 ×5 (2.5%)

### 수익 공식

```
초당 수익 = 생물 권장속도 × 등급 배수 × 아우라 변형 배수 × 러닝머신 배수
```

예) 고래(500K) × 코스믹(×350) × 무지개(×5) = **8.75억/초**, 여기에 터보 러닝머신(×5)이면 **43.75억/초**

러닝머신: 기본 ×1 → 프로 ×2.2 → 터보 ×5 → 퀀텀 ×12 (슬롯 최대 8개)

## 그 외

- 진행상황은 5초마다 **자동 저장** (localStorage)
- 껐다 켜면 최대 2시간치 **오프라인 수익**(50%)을 받는다
- 부화 대기 중 `E` 로 **쓰다듬으면** 성장이 빨라진다
- 가방을 키우면 한 번에 알 1 → 2 → 4 → 7개까지 들 수 있다
- 상점 → 시설 탭에서 **저장 초기화** 가능

## 파일 구조

```
index.html          게임 셸 (HUD · 모달 · 스플래시 DOM)
assets/style.css    로블록스풍 UI 스타일
js/config.js        등급 · 아우라 · 생물 · 보스 · 구역 · 밸런스 상수  ← 밸런스 조정은 여기서
js/util.js          포맷 · 추첨 · 펫 생성 · 캔버스 헬퍼
js/render.js        블록 캐릭터 · 생물 7종 · 아우라 · 알 · 러닝머신 렌더
js/world.js         맵 레이아웃 · 충돌 · 지면 프리렌더
js/input.js         키보드 · 터치 조이스틱
js/sfx.js           WebAudio 효과음
js/ui.js            HUD · 상점 · 도감 · 부화 연출 · 튜토리얼
js/game.js          상태 · 게임 루프 · 훔치기/보스 로직 · 저장

build.js            위 파일들을 전부 인라인해 단일 배포 파일을 만든다
steal-an-egg.html   생성된 단일 파일 (더블클릭 실행용)
```

브라우저 캔버스 2D 만 사용하며 외부 라이브러리·에셋 파일이 전혀 없다. 모든 그래픽은 코드로 그린다.
