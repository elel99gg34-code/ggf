# 🥚 계란을 훔치다 (Steal an Egg)

로블록스풍 브라우저 게임. **자고 있는 파수꾼 옆 둥지에서 알을 훔치고 → 쫓아오는 걸 따돌리고 →
울타리에 넣어 부화시켜 돈을 벌고 → 그 돈으로 러닝머신을 타서 내 속도를 올리는** 게임이다.
빌드 도구·의존성 없음.

**바로 하고 싶으면** → `steal-an-egg.html` 하나만 받아서 더블클릭. (모든 CSS/JS 인라인된 단일 파일)

**소스로 실행**
```
git clone <repo> && cd ggf
# index.html 을 더블클릭하거나
npx http-server -p 8080 .   # → http://localhost:8080
node build.js               # 소스 수정 후 단일 파일 다시 생성
```

## 게임 루프

```
        둥지에서 알을 든다
                ↓
     파수꾼이 깨어나 쫓아온다  ──잡히면──▶  알을 뺏기고 튕겨나간다 (알은 둥지로 복귀)
                ↓ 따돌림
        기지 울타리에 넣는다
                ↓
          부화 → 펫이 초당 돈을 번다
                ↓
     러닝머신을 타고 달려 내 속도 ↑
                ↓
   더 빠른 파수꾼이 있는 구역에 도전 (= 더 좋은 알)
```

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 이동 (모바일은 왼쪽 화면 드래그 = 조이스틱) |
| `E` **꾹 누르기** | 알 훔치기 / 울타리에 넣기 / 러닝머신 달리기 / 울타리 확장 |
| `I` | 내 펫 · `H` 도움말 · `ESC` 닫기 |

---

## 1. 알 훔치기 — 그리고 도망

구역마다 **둥지**가 있고, 둥지 하나에 **파수꾼은 딱 한 마리**가 자고 있다(💤).
**둥지에는 알이 4개** 들어 있고 알마다 등급이 따로 굴려진다.
둥지 옆에서 **E를 꾹** 누르면 맨 앞 알을 들어올리고, **그 순간 파수꾼이 깨어난다.**
한 둥지를 네 번까지 털 수 있지만 매번 새로 깨우게 된다. 다 털린 둥지는 22초 뒤 알 4개로 다시 찬다.

- 깨어난 직후 **0.75초의 틈**(벌떡 일어나는 시간)이 있다. 이때 도망쳐야 한다.
- 잡히면 **알을 뺏기고** 튕겨나간다. 알은 원래 둥지로 돌아간다.
- 파수꾼은 일정 시간이 지나거나 충분히 멀어지면 포기하고 둥지로 돌아가 다시 잠든다.
- 알을 들고 있으면 이동 속도가 8% 느려진다.
- 알은 한 번에 하나만 들 수 있다.

## 2. 울타리 = 수입원

기지 울타리 아래 **알 넣는 곳**에서 `E`. 알은 울타리 안에서 자라 부화하고,
부화한 펫은 울타리를 돌아다니며 **초당 돈을 벌어준다.**
칸이 모자라면 **울타리 확장 패드**를 밟고 `E`. (상점 메뉴는 없다 — 전부 월드 안 설비다)

## 3. 러닝머신 = 내 속도

러닝머신은 펫이 타는 게 아니라 **플레이어가 타는 것**이다.
올라서서 `E`를 꾹 누르면 돈을 쓰면서 달리고, 게이지가 차면 **속도 레벨이 오른다.**

```
내 속도 = 230 × (1 + 0.10 × 속도레벨)      다음 레벨 비용 = 250 × 2.9^레벨
```

## 4. 구역 — 전부 자유 이동

**잠금은 없다.** 처음부터 우주까지 걸어갈 수 있다.
다만 뒤쪽 구역일수록 파수꾼의 **추격 속도**가 빨라서, 내 속도가 그보다 낮으면 절대 못 도망친다.
그게 유일한 난이도 장벽이다.

또 하나의 축이 **구역별 등급 상한**이다. 앞쪽 구역에서는 아무리 굴려도 높은 등급이 나오지 않는다.

| 구역 | 파수꾼 (추격 속도) | 펫 수익 기준값 | 권장 속도 | 최고 등급 |
|---|---|---|---|---|
| 🐔 닭의 숲 | 닭 165 · 갈색 닭 190 | **1** | 0 (시작 속도 230) | 에픽 |
| 🦆 오리 연못 | 오리 215 · 백조 240 | **150** | 240 | 에픽 |
| 🦂 사막 | 전갈 275 · 킹 전갈 300 | **1,000** | 300 | **시크릿** 🚨 |
| 🐯 정글 | 호랑이 340 · 백호 365 | **10,000** | 365 | 디바인 |
| 🐋 바다 | 고래 375 · 범고래 400 | **500,000** | 400 | 코스믹 |
| 🦖 공룡 계곡 | 공룡 430 · 티라노 460 | **1,800,000** | 460 | 영원한 |
| 💀 우주 | 해골장군 500 · 해골왕 545 | **18,000,000** | 545 | 영원한 |

**시크릿은 사막부터** 나온다. 닭의 숲과 오리 연못에서는 일반 · 레어 알 · 에픽만 나온다.

## 5. 등급 & 아우라

| 등급 | 수익 배수 | 기본 확률 | 아우라 |
|---|---|---|---|
| 일반 | ×1 | 55.6% | 없음 |
| 레어 알 | ×3 | 26.7% | 물결 |
| 에픽 | ×9 | 12.2% | 자수정 |
| **시크릿** 🚨 | ×30 | 3.8% | 그림자 |
| **디바인** 🚨 | ×100 | 1.2% | 후광 |
| **코스믹** 🚨 | ×350 | 0.38% | 성운 |
| **영원한** 🚨 | ×1600 | 0.067% | 무한 |

확률은 파수꾼의 `luck` 이 등급 tier 만큼 지수로 곱해져, 뒤쪽 구역일수록 고등급이 잘 나온다.
**아우라 변형**이 등급 위에 한 번 더 곱해진다 — 기본(87%) / ✨빛나는 ×2 (10.5%) / 🌈무지개 ×5 (2.5%)

```
펫 초당 수익 = 구역 기준값 × 등급 배수 × 아우라 변형 배수
```

### 🚨 시크릿 알림

**시크릿 이상** 등급을 훔치거나 부화시키면 화면 위에 **전광판 알림**이 뜬다.
그런 알이 든 둥지는 아래에 등급명이 깜빡이고 **미니맵에도 크게 표시**된다. (그래서 사막 이전 구역에서는 알림이 뜰 일이 없다)
발견 기록은 `I` → 발견 기록 탭에 쌓인다.

## 그 외

- 5초마다 **자동 저장** (localStorage), 껐다 켜면 최대 2시간치 **오프라인 수익**(50%)

## 파일 구조

```
index.html          게임 셸 (HUD · 알림 · 모달 DOM)
assets/style.css    로블록스풍 UI 스타일
js/config.js        등급 · 아우라 · 파수꾼 · 구역 · 밸런스 상수   ← 밸런스 조정은 여기서
js/util.js          포맷 · 추첨 · 펫 생성 · 캔버스 헬퍼
js/render.js        블록 캐릭터 · 생물 7형태 · 둥지 · 아우라 · 울타리 · 러닝머신
js/world.js         맵 레이아웃 · 충돌 · 지면 프리렌더
js/input.js         키보드 · 터치 조이스틱
js/sfx.js           WebAudio 효과음
js/ui.js            HUD · 전광판 알림 · 도감 · 부화 연출 · 튜토리얼
js/game.js          상태 · 게임 루프 · 훔치기/추격/울타리/러닝머신 · 저장

build.js            위 파일들을 인라인해 단일 배포 파일 생성
steal-an-egg.html   생성된 단일 파일 (더블클릭 실행용)
```

캔버스 2D만 사용하며 외부 라이브러리·에셋 파일이 없다. 모든 그래픽은 코드로 그린다.
