# 🎮 GGF 게임 허브

설치 없이 브라우저에서 바로 즐기는 **게임 100개** 모음입니다.
순수 HTML5 Canvas + JavaScript로 만들었고, 외부 라이브러리·이미지 파일 없이 동작합니다.

## 실행 방법

정적 파일만 있으면 되기 때문에 아무 웹 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages 등에 그대로 올려도 동작합니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 허브 (검색, 카테고리, 즐겨찾기, 최근 플레이, 랜덤 플레이) |
| `play.html?g=<id>` | 게임 실행 페이지 |
| `games.js` | 게임 목록 (제목·아이콘·카테고리·설명) |
| `assets/engine.js` | 공용 엔진 (루프, 입력, 터치 패드, 사운드 합성, 파티클, 최고기록 저장) |
| `assets/play.css` | 게임 화면 스타일 |
| `games/*.js` | 게임 100개 (게임당 파일 1개) |

## 공통 기능

- 화면 크기에 맞춰 자동 확대 · 전체화면(F) · 일시정지(P/Esc) · 다시 시작(R)
- 모바일 터치 지원 (스와이프 + 게임별 가상 패드)
- WebAudio로 합성한 효과음 (음소거 가능)
- 게임별 최고기록·플레이 횟수·즐겨찾기를 브라우저(localStorage)에 저장

## 게임 추가하기

1. `games/<id>.js` 파일을 만들고 `GAME({...})`으로 정의합니다.
2. `games.js`의 `GAMES` 배열에 항목을 추가합니다.

```js
let S;
GAME({
  title: '예시', w: 800, h: 600, bg: '#000', controls: 'dpad',
  help: '조작법 한 줄\n두 번째 줄',
  init(g) { S = { x: 400 }; },
  update(g, dt) { S.x += (g.right - g.left) * 300 * dt; if (g.pressed('a')) g.add(10); },
  draw(g, ctx) { g.circle(S.x, 300, 20, '#fff'); },
});
```

엔진 API는 `assets/engine.js` 상단 주석과 `g` 객체 정의를 참고하세요.
