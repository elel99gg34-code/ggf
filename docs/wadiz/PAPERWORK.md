# 와디즈 서류 준비 가이드 (복붙용)

> 사업자등록증, 통신판매업 신고증, 통장 사본, 신분증은 **본인만 발급**받을 수 있다.
> 이 문서는 그 신청서 칸에 무엇을 넣을지 정리한 것이다.
> 세금·법률 자문이 아니다. 업종·과세유형이 애매하면 관할 세무서(국번 없이 126)에 확인한다.

## 순서 (전부 온라인, 보통 1주 안에 끝남)

| # | 할 일 | 어디서 | 걸리는 시간 |
|---|---|---|---|
| 1 | 사업자등록 신청 | 홈택스 | 신청 10분, 발급 보통 1~3일 |
| 2 | 사업자 통장 만들기 | 은행 앱·창구 | 당일 (사업자등록증 필요) |
| 3 | 구매안전서비스 이용확인증 받기 | 와디즈 고객센터 문의 → 안 되면 은행 에스크로 | 1~3일 |
| 4 | 통신판매업 신고 | 정부24 | 신청 10분, 처리 2~3일 + 등록면허세 납부 |
| 5 | 와디즈 메이커 가입·프로젝트 작성 | 와디즈 | 원고·이미지는 이미 준비됨 |

---

## 1. 사업자등록 (홈택스)

**경로**: 홈택스 로그인 → 국세증명·사업자등록 → 사업자등록 신청(개인)

| 칸 | 넣을 값 |
|---|---|
| 상호명 | `로컬비서` (원하는 이름. 나중에 바꿀 수 있음) |
| 개업일자 | 신청하는 날 |
| 사업장 주소 | 집 주소도 된다 (온라인 판매·소프트웨어 개발은 별도 사무실 없이 가능) |
| 사업장 구분 | 본인 소유면 '본인 소유'. 전월세면 임대차계약서 사본 첨부 |
| 업종 1 (주업종) | 업종코드 **722000** · 응용 소프트웨어 개발 및 공급업 (패키지 소프트웨어 판매에 해당) |
| 업종 2 (부업종) | 업종 검색에서 **'전자상거래'** 검색 → '전자상거래 소매업' 선택 (통신판매용) |
| 과세유형 | 아래 '간이 vs 일반' 참고 |
| 공동사업자 | 없음 |
| 연락처·이메일 | 본인 것 |

### 간이과세자 vs 일반과세자
- **간이과세자**
  - 연 매출이 일정 금액 미만으로 예상될 때 고를 수 있다. 부가세 부담이 적다.
  - 직전년도 통신판매 거래 50회 미만이거나 간이과세자면 통신판매업 신고 면제 대상이 될 수 있다. 다만 와디즈가 신고증을 요청할 수 있으니 신고해 두는 쪽을 권한다.
  - 매출 규모에 따라 세금계산서 발행이 제한될 수 있다. 회사 고객(팀 팩)이 세금계산서를 요구하면 불리하다.
- **일반과세자**: 세금계산서를 자유롭게 발행한다. 기업 대상 판매나 매출 증가가 예상되면 이쪽이다.
- **추천**: 첫 펀딩 목표가 수백만 원 수준이면 간이과세로 시작하고, 매출이 늘면 전환한다. 확정 전에 126에 '소프트웨어 패키지 온라인 판매, 예상 연매출 ○○만 원'으로 문의한다.

> 창업 세액감면(청년·지역 요건) 대상 업종인지도 같이 물어보면 좋다.

## 2. 사업자 통장

- 사업자등록증이 나오면 은행에서 **사업자 명의(대표자 본인) 계좌**를 만든다.
- 와디즈 정산 계좌로 쓰고, 통장 사본(계좌번호가 보이는 첫 장)을 PDF·사진으로 저장해 둔다.

---

## 3. 구매안전서비스 이용확인증

- 통신판매업 신고 때 낼 수 있다(선결제 판매일 때).
- **순서**:
  1. 와디즈 고객센터에 "통신판매업 신고용 구매안전서비스 이용확인증 발급 가능 여부"를 먼저 문의한다.
  2. 안 되면 거래 은행의 에스크로 서비스나 결제대행사(PG)에서 발급받는다.

**와디즈 문의 문구 (복붙)**
```
안녕하세요. 리워드형 펀딩을 준비하는 메이커입니다.
통신판매업 신고에 필요한 구매안전서비스 이용확인증(또는 결제대금예치 관련 증빙)을
와디즈 펀딩 기준으로 발급받을 수 있는지 문의드립니다.
리워드는 PC용 소프트웨어 라이선스(디지털 제공, 배송 없음)입니다.
```

## 4. 통신판매업 신고 (정부24)

**경로**: 정부24 → '통신판매업 신고' 검색 → 신청

| 칸 | 넣을 값 |
|---|---|
| 상호·대표자·주소 | 사업자등록증과 똑같이 |
| 전화번호 | 고객 문의 받을 번호 |
| 전자우편 | 고객 문의 받을 이메일 |
| 인터넷 도메인 | 와디즈 프로젝트 주소 (오픈 전이면 메이커 페이지 주소나 홈페이지) |
| 호스트서버 소재지 | 와디즈를 통해 판매하면 와디즈 주소. 정확한 값은 와디즈 고객센터에 확인 |
| 판매방식 | 인터넷 |
| 취급품목 | 컴퓨터/사무용품, 기타 (소프트웨어) |
| 첨부 | 구매안전서비스 이용확인증 |

- 처리가 끝나면 **등록면허세**를 낸다. 지역 인구 규모에 따라 연 1만~4만 원대이고, 위택스에서 낸다.
- 신고증이 나오면 PDF로 저장한다.

## 6. 메이커 정보 칸 (복붙)

**메이커명**
```
로컬비서
```

**메이커 한 줄 소개**
```
파일을 밖으로 보내지 않는 PC 업무 도구를 만듭니다.
```

**메이커 소개**
```
회의 녹음 정리, 개인정보 문서 처리, 상품 사진 편집처럼 매일 반복되지만 외부 서비스에 맡기기엔 찜찜한 일들을 PC 안에서 끝내는 도구를 만듭니다. 구독료 없이 오래 쓸 수 있는 소프트웨어를 지향합니다.
```

**고객 문의 안내**
```
문의: [이메일] / 평일 10:00~18:00 (주말·공휴일은 다음 영업일에 답변)
```
