## 2-1. 프로젝트 소개

**한 줄**
```
파일을 밖으로 보내지 않는 PC 업무 비서, 로컬비서
```

**짧은 소개 (100자 안쪽)**
```
녹음은 회의록으로, 문서 속 주민번호는 자동으로 가리고, 상품 사진은 규격대로. 인터넷 없이 내 PC 안에서 끝나는 업무 비서를 구독료 없이 평생 쓰세요.
```

**본문용 소개**
```
회의 녹음을 정리하려고, 개인정보가 담긴 문서를 가리려고, 상품 사진을 규격에 맞추려고 매번 다른 서비스에 파일을 올리고 계신가요?

로컬비서는 이 일들을 지금 쓰는 PC 안에서 끝내는 업무 비서 프로그램입니다.

녹음 파일을 넣으면 AI가 받아쓰고, 핵심을 요약하고, "누가 언제까지 무엇을" 해야 하는지 할 일과 일정까지 정리합니다. 한글(HWPX)·워드·PDF·사진 속 주민등록번호, 전화번호, 계좌번호, 주소, 이름은 자동으로 찾아 가린 사본을 만들어 줍니다. 상품 사진은 스마트스토어·쿠팡·인스타그램 규격에 맞추고 워터마크까지 폴더째 한 번에 처리합니다.

이 일들은 '자동 처리'로 맡겨 둘 수도 있습니다. 폴더 하나를 정해 두면, 그 폴더에 파일을 넣을 때마다 개인정보를 가리고, 사진을 규격에 맞추고, 영수증은 경비 장부에 적어 둡니다.

여기에 할 일·일정 뽑기, 클립보드 기록, 화면 글자 인식, 영수증·명함 정리, 맞춤법, PDF 도구, 집중 타이머, 통합 검색, 그리고 글자 수·부가세·영업일·QR 같은 작은 도구 10가지까지 비서 기능 14가지가 더 들어 있습니다.

모든 처리는 PC 안에서 이뤄지고, 파일은 서버로 전송되지 않습니다. 인터넷이 없어도 돌아가고, 월 구독료 없이 한 번 결제로 평생 씁니다. 실제 화면을 그대로 녹화한 시연 영상으로 먼저 확인해 보세요.
```

## 5. 기능 전체 설명 (18가지)

> 스토리 중간이나 「자주 묻는 질문」 아래에 그대로 붙여 넣으면 된다.

### 대표 기능 ⓪ 자동 처리

```
📂 자동 처리 — 폴더에 넣기만 하면 알아서

폴더 하나와 할 일 하나를 묶어 '규칙'을 만들어 두면, 그 폴더에 새 파일이 들어올 때마다 로컬비서가 알아서 처리합니다. 창을 닫아도 트레이에서 계속 돌아가요.

· 할 수 있는 일: 개인정보 가리기 / 사진 규격 맞추기(워터마크·자동 보정) / 영수증 → 경비 장부 / 명함 → 연락처 / 사진 → 글자 파일 / 녹음 → 회의록(워드 파일과 할 일까지) / PDF 용량 줄이기
· 결과는 폴더 안 '처리됨'에 (다른 폴더로 정할 수도 있어요). 원본은 그대로 두거나 '원본' 폴더로 옮겨 정리
· 복사·내려받기가 끝난 파일만 처리하고, 임시 파일과 숨김 파일은 건드리지 않아요
· 한 번 처리한 파일은 기억해서 다시 처리하지 않고, 내용이 바뀌면 다시 처리해요
· 언제 무엇을 처리했는지 기록이 남고, 실패한 파일은 '다시 시도' 한 번으로
· 규칙은 여러 개, 켜고 끄기 자유. '지금 확인'으로 기다리지 않고 바로 처리
```

### 핵심 기능 ① 회의록

```
🎙 회의록 — 녹음을 넣으면 회의록·요약·할 일까지

녹음이나 영상 파일을 넣으면 AI 음성 인식이 한국어로 받아쓰고, 핵심 문장을 골라 요약합니다. 대화 속에서 "김 대리가 금요일까지 시안 공유" 같은 할 일을 찾아 담당자·기한과 함께 할 일 목록에 넣고, "다음 주 화요일 오후 2시 촬영" 같은 일정은 캘린더 파일로 만들어 줍니다.

· 지원 파일: mp3, m4a, wav, aac, flac, ogg, mp4, mov, mkv, webm 등
· 정확도 선택: 빠름 / 균형(권장) / 정확함 / 가장 정확함
· 받아쓴 글은 화면에서 눌러 바로 고칠 수 있어요
· 저장 형식: 워드(docx), 텍스트(txt), 마크다운(md), 자막(SRT·VTT)
· '개인정보 가린 사본으로' 저장하면 전화번호·주민번호가 가려진 회의록이 나옵니다
· 녹음이 없어도 회의 메모를 붙여 넣으면 요약과 할 일을 뽑아 줍니다
· "~로 확정했습니다" 같은 결정 사항과 회의에서 자주 나온 낱말을 따로 모아 보여 줍니다
```

## 7. 자주 묻는 질문

```
Q. 인터넷이 꼭 필요한가요?
A. 설치할 때와 AI 모델(음성 인식, 배경 지우기, 번역 언어팩)을 처음 내려받을 때만 필요해요. 그다음부터는 비행기 모드에서도 돌아가요. 라이선스 인증도 인터넷 없이 키 입력만으로 됩니다.

Q. 제 파일이 어딘가로 전송되나요?
A. 아니요. 녹음, 문서, 사진, 메모 모두 PC 안에서만 처리하고 저장해요. 개발사 서버로 보내는 데이터가 없습니다.

Q. 월 구독료가 있나요?
A. 없어요. 한 번 결제로 계속 쓰고, 1년간 업데이트도 무료예요.

Q. 회사 PC와 집 PC에 둘 다 설치할 수 있나요?
A. 라이선스 1개로 PC 2대까지 설치할 수 있어요.

Q. 한글(HWP) 파일도 개인정보를 가릴 수 있나요?
A. HWPX는 서식 그대로 가려요. 구형 HWP는 본문 글자를 가린 텍스트 파일로 저장해요. 한글 프로그램에서 'HWPX로 저장'한 뒤 넣으시면 서식까지 유지됩니다.

Q. 받아쓰기 정확도는 어떤가요?
A. 녹음 품질, 말하는 속도, PC 사양에 따라 달라요. 정확도 단계를 고를 수 있고, 틀린 글자는 화면에서 바로 고칠 수 있어요. 실제 녹음을 그대로 받아쓴 시연 영상으로 미리 확인해 보세요.

Q. 번역 품질은 어떤가요?
A. PC 안에서 돌아가는 작은 번역 모델이라 파파고나 구글 번역보다는 문장이 덜 매끄러워요. 외국어 메일·자료의 뜻을 파악하는 용도로 쓰시고, 밖으로 보낼 글은 한 번 더 확인해 주세요.

Q. 사양이 낮은 PC에서도 되나요?
A. 메모리 8GB 이상이면 대부분의 기능이 돌아가요. 긴 녹음을 회의록으로 바꿀 때는 16GB를 권장하고, 저사양 PC에서는 '빠름' 단계를 쓰시면 돼요.

Q. 체험판이 있나요?
A. 따로 없어요. 실제 앱 화면을 그대로 녹화한 시연 영상(회의록·개인정보 가리기·이미지 처리)과 상세 사양으로 확인해 주세요. 프로그램은 라이선스 키를 등록해야 쓸 수 있어요.

Q. 맥(Mac)에서도 되나요?
A. Apple Silicon(M1 이후) 맥용 설치 파일도 드려요. 아직 Apple 공증 전이라 처음 열 때 앱을 우클릭 → '열기'로 실행해 주세요. 화면 글자 인식(OCR)은 맥에서 Tesseract를 따로 설치해야 해요(brew install tesseract tesseract-lang).
```
