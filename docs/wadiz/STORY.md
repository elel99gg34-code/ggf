## 5. 기능 전체 설명 (16가지)

> 스토리 중간이나 「자주 묻는 질문」 아래에 그대로 붙여 넣으면 된다.

### 핵심 기능 ① 회의록

```
🎙 회의록 — 녹음을 넣으면 회의록·요약·할 일까지

녹음이나 영상 파일을 넣으면 AI 음성 인식이 한국어로 받아쓰고, 핵심 문장을 골라 요약합니다. 대화 속에서 "김 대리가 금요일까지 시안 공유" 같은 할 일을 찾아 담당자·기한과 함께 할 일 목록에 넣고, "다음 주 화요일 오후 2시 촬영" 같은 일정은 캘린더 파일로 만들어 줍니다.

· 지원 파일: mp3, m4a, wav, aac, flac, ogg, mp4, mov, mkv, webm 등
· 정확도 선택: 빠름 / 균형(권장) / 정확함 / 가장 정확함
· 받아쓴 글은 화면에서 눌러 바로 고칠 수 있어요
· 저장 형식: 워드(docx), 텍스트(txt), 마크다운(md), 자막(SRT·VTT)
· '개인정보 가린 사본으로' 저장하면 전화번호·주민번호가 가려진 회의록이 나옵니다
· 녹음이 없어도 회의 메모를 붙여 넣으면 요약과 할 일을 뽑아 줍니다
· AI 모델은 처음 쓸 때 한 번만 내려받고, 그다음부터는 인터넷 없이 돌아갑니다
```

### 핵심 기능 ② 개인정보 가리기

```
🛡 개인정보 가리기 — 문서·이미지 속 개인정보를 자동으로

문서를 넣으면 개인정보를 찾아 가린 '_마스킹' 사본을 만듭니다. 원본은 건드리지 않습니다.

· 찾는 항목: 주민등록번호(외국인등록번호 포함), 전화번호, 카드번호, 계좌번호, 이메일, 여권번호, 운전면허번호, 차량번호, 이름, 주소, 사업자번호, IP 주소, 얼굴
· 가리는 방식 3가지
  - 일부만: 010-****-5678, 900101-1******, 홍*동
  - 전부: ***-****-****
  - 항목 이름: [전화번호]
· 한글(HWPX)·워드(DOCX): 글자 모양·표·머리글·바닥글 그대로, 문서 속 작성자 정보도 지움
· PDF: 개인정보가 있는 쪽은 검게 칠하고 글자 자체를 지워서, 복사·검색해도 원문이 나오지 않음. 스캔 PDF도 글자 인식으로 찾음
· 이미지(PNG·JPG 등): 사진 속 글자를 읽어 해당 위치를 칠하고, 얼굴은 모자이크
· 텍스트·CSV 파일 지원, 여러 파일 한 번에
· 구형 한글(HWP)은 본문 글자만 가린 텍스트 파일로 저장 (서식이 필요하면 HWPX로 저장해서 넣어 주세요)
· 붙여 넣은 글을 바로 가리는 기능도 있어요

※ 자동 탐지는 사람의 최종 확인을 대신하지 않습니다. 결과 파일을 꼭 한 번 확인해 주세요.
```

### 핵심 기능 ③ 이미지·영상

```
🖼 이미지·영상 — 마켓 규격 맞추기, 워터마크, 무음 컷, 자막

[이미지 일괄 처리]
· 규격 프리셋: 스마트스토어 대표(1000×1000), 쿠팡 대표(1000×1000), 상세페이지(가로 860), 인스타 정사각(1080×1080), 인스타 세로(1080×1350), 썸네일(500×500), 직접 입력
· 맞추는 방식: 여백 넣기 / 잘라 채우기 / 안에 맞추기
· 워터마크: 위치 6가지(바둑판 포함), 진하기, 색 조절
· 배경 지우기 (AI 모델, 처음 한 번 내려받기)
· 저장 형식 JPG·PNG·WEBP, 화질 조절, 폴더째 한 번에

[영상]
· 무음 구간 자동 컷: 말이 없는 부분만 잘라 내서 영상 길이를 줄여 줍니다. 자르기 전에 몇 분이 줄어드는지 미리 계산
· 자막 만들기: 영상 속 말을 받아써 SRT 자막 파일로 저장
```

### 비서 기능 ④~⑯

```
✅ 할 일 뽑기
회의 메모, 메일, 메신저 대화를 붙여 넣으면 해야 할 일을 찾아 담당자·기한과 함께 정리합니다. 확인 후 버튼 한 번으로 할 일 목록에 넣으세요.
```
```
📅 일정 뽑기
"내일 오후 3시", "다음 주 화요일 10시 반", "11월 3일 2시~4시" 같은 표현을 찾아 캘린더 파일(.ics)로 만듭니다. 구글·아웃룩·애플 캘린더에 바로 추가돼요.
```
```
📝 메모·할 일
메모장과 할 일 목록. 기한이 다가오면 '오늘', '내일', '2일 지남'으로 표시되고, 중요한 메모는 위에 고정할 수 있어요.
```
```
📋 클립보드 기록
복사한 글을 최근 500개까지 기억해 두었다가 다시 꺼내 씁니다. 주민번호·카드번호 같은 민감정보는 가려서 저장하거나 아예 저장하지 않도록 고를 수 있어요.
```
```
🔍 화면 글자 인식
Ctrl + Shift + O를 누르면 화면을 캡처하고, 읽을 부분을 끌어서 고르면 글자로 바꿔 줍니다. 이미지 파일도 넣을 수 있고, 읽은 글자는 번역이나 영수증 정리로 바로 보낼 수 있어요.
```
```
🧾 영수증·명함 정리
영수증 사진을 넣으면 가맹점·날짜·금액·사업자번호를 읽어 경비 장부에 넣고, 월별 엑셀로 내보냅니다. 명함 사진은 이름·회사·직함·전화·이메일을 읽어 휴대폰 연락처 파일(vCard)로 만들어요.
```
```
🌐 번역
한국어·영어·일본어·중국어를 인터넷 없이 번역합니다. 언어팩은 처음 한 번만 내려받아요.
```
```
✍️ 글다듬기
'몇일→며칠', '할께요→할게요', '안되요→안 돼요' 같은 자주 틀리는 맞춤법을 고치고, 해요체 ↔ 합니다체 ↔ 공문체(~함, ~임)로 문체를 바꿉니다. 받는 사람과 할 말만 쓰면 업무 메일 틀도 만들어 줘요.
```
```
🏷 파일 이름 일괄 변경
'여행_001.jpg'처럼 번호·날짜·사진 찍은 날짜를 넣어 한 번에 이름을 바꿉니다. 바뀔 이름을 먼저 보여 주고, 잘못 바꿨으면 되돌릴 수 있어요.
```
```
🗂 중복 파일 정리
내용이 똑같은 파일과 거의 같은 사진을 찾아 묶어 보여 줍니다. 바로 지우지 않고 보관함으로 옮겨서 언제든 되돌릴 수 있어요.
```
```
📄 PDF 도구

## 7. 자주 묻는 질문

```
Q. 인터넷이 꼭 필요한가요?
A. 설치할 때와 AI 모델(음성 인식, 배경 지우기)을 처음 내려받을 때만 필요해요. 그다음부터는 비행기 모드에서도 돌아가요. 라이선스 인증도 인터넷 없이 키 입력만으로 됩니다.

Q. 제 파일이 어딘가로 전송되나요?
A. 아니요. 녹음, 문서, 사진, 메모 모두 PC 안에서만 처리하고 저장해요. 개발사 서버로 보내는 데이터가 없습니다.

Q. 월 구독료가 있나요?
A. 없어요. 한 번 결제로 계속 쓰고, 1년간 업데이트도 무료예요.

Q. 회사 PC와 집 PC에 둘 다 설치할 수 있나요?
A. 라이선스 1개로 PC 2대까지 설치할 수 있어요.

Q. 한글(HWP) 파일도 개인정보를 가릴 수 있나요?
A. HWPX는 서식 그대로 가려요. 구형 HWP는 본문 글자를 가린 텍스트 파일로 저장해요. 한글 프로그램에서 'HWPX로 저장'한 뒤 넣으시면 서식까지 유지됩니다.

Q. 받아쓰기 정확도는 어떤가요?
A. 녹음 품질, 말하는 속도, PC 사양에 따라 달라요. 정확도 단계를 고를 수 있고, 틀린 글자는 화면에서 바로 고칠 수 있어요. 구매 전에 14일 체험판으로 직접 확인해 보세요.

Q. 사양이 낮은 PC에서도 되나요?
A. 메모리 8GB 이상이면 대부분의 기능이 돌아가요. 긴 녹음을 회의록으로 바꿀 때는 16GB를 권장하고, 저사양 PC에서는 '빠름' 단계를 쓰시면 돼요.

Q. 체험판이 있나요?
A. 네. 설치 후 14일 동안 모든 기능을 무료로 쓸 수 있어요. 체험판 다운로드: [링크]

Q. 맥(Mac)에서도 되나요?
A. [macOS 제공 일정과 지원 범위를 입력]
```

## 8. 펀딩금 반환 정책 (청약철회)

```
1. 펀딩 기간 중에는 와디즈에서 언제든 결제를 취소할 수 있어요.

3. 키를 확인하면 디지털 콘텐츠 제공이 시작된 것으로 보고 청약철회가 제한돼요(전자상거래법 제17조 제2항 제5호). 구매 전에 14일 무료 체험판으로 미리 써 볼 수 있어요.
4. 2인·5인 팩은 확인하지 않은 키 수만큼 환불해 드려요.
5. 프로그램이 소개 내용과 다르거나 결함으로 핵심 기능을 쓸 수 없는데 14일 안에 고치지 못하면, 키 확인 여부와 상관없이 환불해 드려요.
6. 제공 예정일보다 30일 넘게 늦어지면 원하는 서포터께 전액 환불해 드려요.
7. 환불은 신청을 받은 날부터 3영업일 안에 처리해요.
