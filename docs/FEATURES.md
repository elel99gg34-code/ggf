## 상담 스킬 코치 상세

- **6개 분야 27개 스킬**: 아이와 대화, 감정 코칭, 부부·가족 대화, 선생님 상담, 병원·전문가 상담, 나를 위한 대화
- 스킬마다 *왜 중요한가 / 단계별 방법 / 이렇게 말해보세요 / 피해야 할 말 / 상황 예시 / 오늘의 미션* 구성
- **상담 스킬 알람**: 시각·요일·분야를 정하거나 특정 스킬을 고정하면 매번 알람처럼 오늘의 스킬이 알림으로 온다. 알림을 누르면 해당 스킬 연습 화면이 열린다. 추천 알람 2개를 한 번에 추가할 수 있다.
- 연습 기록, 연속 학습 일수, 즐겨찾기, 나만의 메모, 처음 배우는 순서(스타터 패스), 상황별 한 마디
- **상담 일지**: 상담 대상(아이·배우자·양가·선생님·의사·나)별 목표 → 잘된 점 → 다음에 해볼 것 기록

## 추가된 10가지 기능

1. 진통 타이머 — 간격·지속시간 자동 계산, 5-1-1 기준 도달 시 경고
2. 임신 주차·태동 카운터 — 예정일 기반 주차, 주차별 아기·엄마 변화와 할 일, 태동 10회 카운트
3. 돌봄 인수인계 노트 — 일과·식사·수면·약·규칙·비상시 정보를 알레르기·비상연락처와 함께 공유
4. 소모품 재고 — 하루 사용량으로 소진일 예측, 부족 경고, 장보기 연동
5. 수유·수면 패턴 분석 — 평균 수유 간격, 다음 수유 예상, 시간대별 분포, 수면 인사이트
6. 집 안전 점검 — 공간별 체크리스트 템플릿
7. 외출 가방 체크 — 다녀온 뒤 초기화해서 재사용
8. 아이 습관 루틴 — 주간 체크, 연속 일수, 달성 시 칭찬 스티커 자동 지급
9. 그림책 독서 기록 — 읽은 시간 통계, 월령별 추천 유형
10. 레시피북 — 기본 이유식·유아식·간식·아플 때 레시피, 월령 필터, 재료를 장보기에 담기
