# 프로그램 저작권 등록 자료 (선택)

와디즈 심사에서 "프로그램 권리가 메이커에게 있다"는 증빙으로 쓸 수 있다. 등록은 필수가 아니다. 개발 저장소와 커밋 기록만으로도 증빙이 될 수 있다.

## 들어 있는 파일

| 파일 | 내용 |
|---|---|
| `프로그램명세서.docx` | 명칭·버전·저작자·개요·기능·구성·환경·규모·제외 범위·AI 활용 |
| `소스코드_전체.pdf` | 직접 작성한 소스 81개 파일 전체 (줄 번호, 파일 경로 표시) |
| `소스코드_발췌.pdf` | 앞 25쪽 + 뒤 25쪽 (일부 제출이 허용될 때) |

다시 만들기:
```bash
python tools/copyright_kit.py --author "본인 이름" --made 2026-10-25
```

## 신청 순서

1. 한국저작권위원회 저작권등록 누리집(cros.or.kr)에 회원가입한다.
2. 등록 신청 → 저작물 종류 **'컴퓨터프로그램저작물'**을 고른다.
3. 신청서를 입력한다. 명세서 내용을 옮겨 쓰면 된다.
4. 복제물을 올린다. 전체 소스 제출이 필요한지, 발췌본으로 되는지는 신청 화면 안내를 따른다.
5. 수수료를 내면 심사 후 등록증이 나온다.

정확한 제출 범위와 수수료는 신청 화면이나 위원회 안내에서 확인한다.

## ⚠️ 꼭 확인할 것: 생성형 AI로 작성된 코드

이 프로그램의 소스코드는 상당 부분을 **생성형 AI(Claude)가 작성**했다.

- 우리나라 저작권 제도에서는 사람의 창작적 기여가 있는 부분만 저작물로 보호한다.
- 저작권 등록 실무에서도 AI가 만든 부분의 등록 가능 범위와 AI 활용 사실 기재가 쟁점이다.

그래서 다음을 지킨다.
- 명세서 「5. 생성형 AI 활용 여부」에 **사실대로** 적는다. 본인이 기획·구성·선택·수정한 부분을 구체적으로 쓴다.
- 신청 전에 위원회에 AI 활용 저작물의 등록 가능 범위를 문의한다.
- AI 활용을 숨기고 등록하면 등록이 무효가 되거나 문제가 될 수 있다.

- 이 명세서
