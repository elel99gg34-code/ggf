# 와디즈 펀딩 입력 자료: 로컬비서

> **복붙용 원고**는 [`wadiz/STORY.md`](wadiz/STORY.md), **스토리 이미지 14장**은 [`wadiz/images/`](wadiz/images/)에 있다.
> 이미지 문구·가격을 바꾸려면 `tools/wadiz/story.html`을 고치고 `cd tools/wadiz && npm install && node render.mjs`를 실행한다.

> 와디즈 메이커 스튜디오(리워드형 펀딩)의 입력 항목 순서대로 정리했다.
> 수수료, 목표 금액 하한, 펀딩 기간 상한 같은 정책 수치는 자주 바뀐다. 오픈 전에 메이커 스튜디오의 최신 안내를 꼭 확인할 것.
> 환불·청약철회 문구는 법률 자문이 아니다. 최종본은 와디즈 심사 담당자나 전문가 확인을 받는다.

## 1. 무슨 프로그램인가 (한 문단)

**로컬비서**는 인터넷 없이 내 PC 안에서만 돌아가는 업무 비서 프로그램이다. 녹음 파일을 회의록으로 바꾸고, 문서 속 주민번호·전화번호·계좌 같은 개인정보를 자동으로 가리고, 상품 이미지와 영상을 한 번에 정리한다. 여기에 할 일, 일정, 클립보드, 화면 글자 인식, 영수증·명함 정리, 번역, 맞춤법, 파일 정리, PDF 도구, 집중 타이머, 통합 검색, 작은 도구 10가지까지 비서 기능 14가지가 들어 있다. 대표 기능 '자동 처리'는 폴더에 파일을 넣기만 하면 이 일들을 알아서 한다. 파일을 서버에 올리지 않고, 매달 내는 구독료 없이 한 번 결제로 계속 쓴다.

## 3. 리워드 설계

모든 리워드는 **디지털 제공(배송 없음)**이다. 라이선스 키를 이메일과 와디즈 메시지로 보낸다.

| 리워드 | 금액 | 수량 | 구성 |
|---|---|---|---|
| 슈퍼얼리버드 | 29,000원 | 선착순 100 | 평생 라이선스 1개 (PC 2대), 1년 무료 업데이트 |
| 얼리버드 | 39,000원 | 선착순 300 | 위와 같음 |
| 기본 | 49,000원 | 제한 없음 | 위와 같음 |
| 2인 팩 | 89,000원 | 제한 없음 | 라이선스 2개 (각 PC 2대) |
| 팀 5인 팩 | 199,000원 | 50 | 라이선스 5개, 사무실 설치 안내 문서 |

- **정가 표기**: 펀딩 후 정가 69,000원으로 표기하면 할인율이 보인다. 실제로 그 가격에 팔 계획이 있을 때만 쓴다.
- **스트레치 골**:
  - 500%: 화자 분리 정식판
  - 1000%: 맥(Apple Silicon) 최적화
  - 2000%: 로컬 AI 요약 모델 기본 포함

### 리워드 공통 입력값
- **배송 필요 여부**: 없음 (디지털)
- **제공 예정일**: 펀딩 종료 후 **2주 이내** 라이선스 키와 설치 파일 링크 발송
  - 정식 1.0이 그때까지 안 끝날 것 같으면, 날짜를 실제 완성 일정 + 2주 여유로 잡는다.
- **옵션**: 운영체제 선택 (Windows / macOS). 키는 공용이라 둘 다 쓸 수 있다고 안내한다.

## 4. 스토리 (본문 구성)

1. **훅**: "회의 녹음, 아직도 클라우드에 올리세요?"
   - 30초 시연 GIF: 녹음 파일을 드래그 → 회의록 생성 → 주민번호가 자동으로 `******` 처리
2. **이런 분께**:
   - 녹음을 정리해야 하는 기자, 학생, 상담사, 노무·세무 사무실
   - 개인정보 문서를 다루는 학교, 병원, 공공기관 담당자
   - 상품 이미지를 매일 손보는 스마트스토어·쿠팡 셀러
3. **대표 기능: 자동 처리**:
   - 폴더를 정해 두면 새 파일이 들어올 때마다 알아서 처리: 개인정보 가리기, 사진 규격, 영수증→경비 장부, 명함→연락처, 사진→글자, 녹음→회의록, PDF 압축
   - 결과는 '처리됨' 폴더, 원본은 그대로 또는 '원본' 폴더로. 처리 기록과 실패 다시 시도
4. **핵심 기능 3가지** (각각 시연 영상):
   - 오프라인 회의록: 받아쓰기, 요약, 할 일·일정·결정 사항 자동 추출, 워드·자막 파일 저장
   - 개인정보 자동 가림: HWPX·DOCX·XLSX·PDF·이미지·텍스트 지원. 주민번호, 전화, 카드, 계좌, 이메일, 여권, 면허, 차량번호, 주소, 이름, 얼굴. '항상 가릴 말'·'가리지 않을 말' 지정, 확인용 보고서
   - 이미지·영상 일괄 처리: 스마트스토어·쿠팡·인스타·유튜브·블로그·배달앱 규격, 자동 보정, 워터마크, 배경 제거, 무음 구간 자동 컷, 자막 생성
5. **비서 기능 14가지** (아이콘 그리드):
   - 할 일 자동 추출, 일정 추출(.ics), 메모·할 일, 클립보드 기록(민감정보 자동 가림), 화면 글자 인식
   - 영수증·명함 정리(엑셀·연락처), 오프라인 번역, 맞춤법·문체 변환, 파일 이름 일괄 변경
   - 중복 파일 정리, PDF 합치기·나누기·압축, 집중 타이머·주간 리포트, 통합 검색(Ctrl+Space)
   - 작은 도구 10가지: 글자 수, 금액 한글·부가세, 날짜·영업일, QR·와이파이 QR, 비밀번호, 한영 타자 변환, 글 정리, 단위 변환, 번호 확인, 엑셀·CSV 합치기
6. **왜 로컬인가**:
   - 파일이 PC 밖으로 나가지 않는다.
   - 인터넷이 끊겨도 된다.
   - 사용량 제한과 월 구독료가 없다.
7. **비교표**: 클라우드 녹음 서비스(월 구독, 업로드 필수) vs 로컬비서(한 번 결제, 업로드 없음)
8. **개발 현황**: 실제 작동 화면, 테스트 결과, 로드맵
9. **사양·이용 조건, 환불 정책, FAQ** (아래 5~7)

## 5. 이용 조건 (상품정보제공고시: 디지털 콘텐츠)

| 고시 항목 | 내용 |
|---|---|
| 제작자/공급자 | (메이커명 / 사업자명 입력) |
| 이용 조건 | 라이선스 1개당 1인 사용, PC 최대 2대 설치. 상업적 업무 사용 가능. 재판매·공유·키 양도 금지 |
| 이용 기간 | 구매한 버전과 1년 안에 나온 업데이트를 기간 제한 없이 사용 (평생 라이선스). 1년 이후 업데이트는 선택 구매 예정 |
| 상품 제공 방식 | 이메일로 라이선스 키와 다운로드 링크 발송. 키는 인터넷 없이 입력만으로 활성화 |
| 최소 시스템 사양 | Windows 10/11 64비트 또는 macOS 12 이상, RAM 8GB 이상(회의록 기능은 16GB 권장), 저장 공간 2GB + AI 모델 1~3GB |
| 필수 소프트웨어 | 없음 (설치 파일에 모두 포함). AI 모델은 처음 쓸 때 한 번 내려받음 (인터넷 필요) |
| 청약철회/해제 효과 | 아래 '환불 정책' 참고 |
| 소비자 상담 | (전화번호 / 이메일 / 응답 시간 예: 평일 10~18시) |

### 꼭 넣을 안내 문구
- 모든 처리는 PC 안에서 이뤄지고, 사용자의 파일과 기록은 개발사 서버로 전송되지 않는다.
- 인식 정확도는 녹음 품질, 문서 상태, PC 사양에 따라 다르다. 개인정보 자동 가림은 사람의 최종 확인을 대신하지 않는다.
- HWP(구형 바이너리)는 본문 텍스트만 가린 .txt로 저장된다. 서식을 유지하려면 HWPX로 저장해서 쓴다.
- 화자 분리는 실험 기능이다.

## 6. 펀딩금 반환(환불)과 청약철회

### 법 기준 (전자상거래법, 요약)
- **제17조 1항**: 계약 내용을 받은 날(제공이 늦으면 제공받은 날)부터 7일 이내 청약철회 가능
- **제17조 2항 5호**: 디지털 콘텐츠는 **제공이 개시되면** 철회를 제한할 수 있다.
  - 나눌 수 있는 콘텐츠라면, 제공이 개시되지 않은 부분은 제한할 수 없다.
- **제17조 6항**: 철회를 제한하려면 다음 조치가 필요하다. 하지 않으면 제한할 수 없다.
  - 철회 불가 사실을 잘 보이게 표시
  - **시험 사용 상품(체험판)** 제공 같은 조치 (시행령 제21조의2: 일부 이용·기간 한정 이용·체험판, 이것들이 곤란하면 콘텐츠 정보 제공)
- **제17조 3항**: 표시·광고와 다르게 제공되면 기간 안에 철회할 수 있다. 제2항(제공 개시)과 상관없다.
  - 기간: 제공받은 날부터 3개월, 그 사실을 안 날부터 30일
  - 그래서 **아직 없는 기능은 반드시 '예정'으로 표시**한다.
- **제18조**: 철회를 받으면 3영업일 안에 환불한다.
- **와디즈 자체 정책**: 법보다 넓게 반환을 요구할 수 있다. 메이커 스튜디오의 반환 정책 가이드를 우선한다.

### '제공 개시' 시점 정하기
라이선스가 오프라인 활성화라서, 구매자가 키를 실제로 썼는지 판매자가 확인할 수 없다. 그래서 **키를 열람하는 순간**을 제공 개시로 정하고 기록을 남긴다.
1. 이메일에는 키 대신 "키 확인하기" 링크를 보낸다. → 라이선스 발급 서버가 보내는 안내 메일이 이렇게 동작한다.
2. 링크 페이지에 아래 문구와 동의 버튼을 두고, 누른 시각을 기록한다. → 서버의 키 확인 페이지가 처음 연 시각을 남기고, 발급 기록에 '키 열람 날짜'로 보여 준다(CSV에도 들어감).
   - 문구: "키를 확인하면 디지털 콘텐츠 제공이 시작되어 청약철회가 제한됩니다(전자상거래법 제17조 제2항 제5호). 시연 영상과 상세 사양으로 먼저 확인해 주세요."
3. 앱의 라이선스 입력 화면에도 같은 고지를 띄운다(앱에 반영됨).
4. **무료 체험판은 두지 않는다.** 대신 시연 영상 3개와 상세 사양·지원 형식을 스토리에 자세히 적는다(시행령 제21조의2 제4호 '콘텐츠 정보 제공').
   - 주의: 이 방식은 체험판을 줄 때보다 철회 제한 근거가 약하다. 와디즈 PD가 바꾸라고 하거나 분쟁이 생기면 아래 '보수적 문구'로 바꾼다.
   - 보수적 문구: "키를 받은 날부터 7일 안에는 키를 등록했더라도 환불해 드려요. 환불하면 그 키는 사용 중지 목록에 올라가요." (앱이 오프라인이라 실제로 막을 수는 없어서, 악용 위험은 판매자가 진다)

### 와디즈 입력용 문구
1. 펀딩 기간 중에는 와디즈에서 언제든 결제를 취소할 수 있어요.
2. 펀딩 종료 후 라이선스 키를 **확인(열람)하기 전**이라면 7일 안에 전액 환불해 드려요.
3. 키를 확인하면 디지털 콘텐츠 제공이 시작된 것으로 보고 청약철회가 제한돼요(전자상거래법 제17조 제2항 제5호). 구매 전에 **시연 영상과 상세 사양**으로 기능을 확인해 주세요.
4. 2인·5인 팩은 **확인하지 않은 키 수만큼** 환불해 드려요.
5. 프로그램이 소개 내용과 다르거나 결함으로 핵심 기능을 쓸 수 없는데 14일 안에 고치지 못하면, 키 확인 여부와 상관없이 환불해 드려요.
6. 제공 예정일보다 30일 넘게 늦어지면 원하는 서포터에게 전액 환불해 드려요.
7. 환불은 신청을 받은 날부터 3영업일 안에 처리해요.

## 7. 예상되는 어려움 (리스크)

- **일정 지연**: 기능이 많아 일정이 밀릴 수 있다.
  - 코어 3가지와 비서 기능을 먼저 제공하고, 나머지는 업데이트로 순차 제공한다.
  - 지연 시 매주 새소식으로 진행 상황을 공개한다.
- **사양에 따른 속도 차이**: 저사양 PC에서는 회의록 변환이 느릴 수 있다.
  - 빠른 모델/정확한 모델을 고를 수 있게 하고, 시연 영상과 권장 사양으로 미리 안내한다.
- **인식 오류**: 개인정보 탐지에서 놓치거나 잘못 가리는 경우가 있을 수 있다.
  - 결과 미리보기와 항목별 개수를 보여주고, 사람이 최종 확인하도록 안내한다.
- **운영체제 업데이트 호환성**: 문제가 생기면 무료 업데이트로 대응한다.

## 8. 메이커 정보와 제출 서류 (준비물)

> 와디즈는 메이커의 업력·유형과 리워드 종류에 따라 필요한 서류를 다르게 요구한다(2025년 펀딩 개설 요건 변경 공지).
> 공개된 고정 목록은 없으니 아래를 준비해 두고, 최종 목록은 메이커 스튜디오에서 프로젝트를 만들 때 나오는 요청을 따른다.

### 거의 확실히 필요한 것
- **사업자등록증**: 개인사업자 또는 법인. 법인이면 법인등기부등본도 준비한다.
  - 업종 예시: 응용 소프트웨어 개발 및 공급업, 전자상거래 소매업
- **통신판매업 신고증**
  - 글로벌·앵콜 펀딩에서는 필수로 확인됐다.
  - 일반 펀딩도 와디즈가 요청할 수 있다(메이커 이용약관).
  - 펀딩 후 직접 판매까지 하려면 어차피 필요하니 미리 신고한다.
  - 신고할 때 구매안전서비스 이용확인증이 필요할 수 있다. 발급 방법은 와디즈 고객센터에 문의한다.
- **대표자 본인 인증과 신분증**
- **정산 계좌 통장 사본**: 사업자 대표자(법인은 법인) 명의

### 소프트웨어 리워드라서 준비할 것
- **실제 작동 증빙**: 시연 영상(회의록·마스킹·이미지, 각 15~40초)
- **지식재산권 증빙**: 와디즈 심사 정책에 '상표등록원부, 라이선스 계약서'가 요청 가능 서류로 나온다.
  - 프로그램 저작권이 메이커에게 있다는 자료: 개발 저장소, 커밋 기록
  - (선택) 한국저작권위원회 프로그램 저작권 등록증
  - (선택) '로컬비서' 상표 출원서
  - 오픈소스 라이선스 목록: `docs/OPEN_SOURCE.md`
- **상품정보제공고시(디지털 콘텐츠)**: 이 문서 5번에 있다.
- 해당 없음: KC 인증, 시험성적서, 수입신고필증, 위탁제조계약서 (실물 제품이 아님)

### 입력할 메이커 정보
- 메이커명, 프로필 이미지, 한 줄 소개
- 사업자명, 사업자등록번호, 대표자명
- 문의 이메일·전화, 응답 시간
- 홈페이지·인스타(있으면)
- 요금제 선택 (첫 프로젝트 할인 여부 확인)

## 9. FAQ (스토리 하단)

- **Q. 인터넷이 꼭 필요한가요?**
  - A. 설치와 AI 모델 첫 다운로드 때만 필요해요. 그 뒤로는 비행기 모드에서도 돌아가요. 라이선스 활성화도 오프라인으로 돼요.
- **Q. 월 구독료가 있나요?**
  - A. 없어요. 한 번 결제로 계속 써요.
- **Q. 회사 PC와 집 PC에 둘 다 깔 수 있나요?**
  - A. 라이선스 1개로 2대까지 돼요.
- **Q. 한글(HWP) 파일도 되나요?**
  - A. HWPX는 서식 그대로 가려요. 구형 HWP는 본문 텍스트를 가린 파일로 저장해요.
- **Q. 맥에서도 되나요?**
  - A. macOS 12 이상을 지원해요. 첫 제공은 Windows가 먼저일 수 있어요. (실제 일정에 맞춰 수정)
- **Q. 녹음 파일 형식은요?**
  - A. mp3, m4a, wav, mp4, webm 등 흔히 쓰는 음성·영상 파일은 대부분 돼요.
