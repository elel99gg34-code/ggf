# 맘케어 설치하기 (안드로이드 휴대폰)

<img src="images/install-qr.png" width="220" alt="설치 QR 코드">

**휴대폰 카메라로 QR을 찍거나 아래 링크를 누르면 설치 파일(APK)이 바로 내려받아진다.**

- 바로 내려받기: https://github.com/elel99gg34-code/ggf/releases/download/momcare-latest/momcare.apk
- 릴리스 페이지(설명 포함): https://github.com/elel99gg34-code/ggf/releases/tag/momcare-latest

## 설치 순서
1. 링크를 열면 `momcare.apk`가 내려받아진다. ("이 파일은 기기에 해를 끼칠 수 있습니다" 안내가 나오면 **다운로드**를 누른다.)
2. 내려받은 파일을 연다.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와 **설치**를 누른다.
4. 앱을 열고 가족 비밀번호를 한 번 입력한다.
5. 육아·임신 기능이 필요하면 **설정 → 기능 표시**에서 켠다.

## 업데이트
같은 링크(QR)에서 다시 내려받아 설치하면 기록이 그대로 유지된 채 최신 버전으로 바뀐다. 앱은 코드가 바뀔 때마다 GitHub Actions에서 자동으로 빌드된다.

## 참고
- 안드로이드 8.0 이상에서 동작한다. 아이폰(iOS)은 지원하지 않는다.
- Play 스토어가 아니라 직접 설치하는 방식이라 Play 프로텍트 경고가 나올 수 있다. 이 저장소에서 빌드한 파일만 설치한다.
